# Smart Travel Planner

Smart Travel Planner is a modern full-stack Django web application that helps users plan trips, manage bookings, generate AI-based itineraries, make payments, download PDF travel reports, and explore destinations with Google Maps integration.

---

## Features

- User Signup/Login Authentication
- Role-Based User System
- AI Trip Planner
- Destination Explorer
- Google Maps Integration
- Travel Booking System
- GPay QR Payment System
- Booking Confirmation
- PDF Travel Report Download
- Reviews & Ratings
- Analytics Dashboard
- Dark Mode
- Responsive Bootstrap UI
- Django Admin Panel

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/smart-travel-planner.git
```

### Open Project

```bash
cd smart-travel-planner
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

#### Windows

```bash
venv\Scripts\activate
```

### Install Requirements

```bash
pip install -r requirements.txt
```

### Run Migrations

```bash
python manage.py makemigrations
```

```bash
python manage.py migrate
```

### Run Server

```bash
python manage.py runserver
```
